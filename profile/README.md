### What we do

Enterprise software is priced per seat, per module, per year. For many businesses, the same work runs on open-source software and a well-specified server, at a fixed monthly cost. We move what pays back, keep what works, and stay on to maintain it.

### How we work

| | Stage | What happens |
|---|---|---|
| **I** | Survey | Discovery call and audit: what you pay for, what your team uses, your real traffic and load |
| **II** | Select | Open-source alternatives scored on the Selection Matrix; only tools that pass, and pay back, make the shortlist |
| **III** | Build | Deployed on a right-sized server, data migrark |
| **IV** | Keep | Updates, security patches, backups, monitoring, and new features as the business changes |

### The Selection Matrix

Free isn't the bar. Fit is. Every tool clears four tests before we recommend it:

- **Maintenance:** release cadence, issue response, active maintainers
- **Security:** vulnerability history, disclosure policy, patch speed, access model
- **Licensing:** licence type, copyleft obligations, features he
- **Community:** contributors, ecosystem, documentation, hiring pool

### Reference setup

- **Public apps** reach the world through a [Cloudflare Tunnel](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/) that the server
dials out to, so there are no open inbound ports.
- **Internal apps** sit on a private [Tailscale](https://tailscale.com) or [NetBird](https://netbird.io) network that only your team's devices can join.
- **Your server, your data, your exit:** the infrastructure is in your name.
